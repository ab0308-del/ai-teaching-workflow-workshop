# AI 神隊友｜常見 AI 工具的教學工作流

45 頁、16:9 響應式網頁簡報，內含「不同工作情境下的 AI 工具選擇」即時投票。

## 檔案

- `index.html`：簡報入口（方向鍵／點擊換頁，N 開講者備註）。
- `slides-data.js`：45 頁文字、提示詞、講者備註。
- `app.js`、`styles.css`：版型與換頁。
- `vote.html`：老師用手機投票的頁面（簡報第 4 頁 QR Code 會連過來）。
- `vote-config.js`：10 個工作情境、凱琳老師的選擇與理由、資料庫設定。**要改答案或理由，改這個檔就好。**
- `vote-board.js`：簡報第 4 頁與第 43 頁的即時結果看板。

## 投票怎麼用

1. 第 4 頁：老師掃 QR Code 作答，結果每 3 秒自動更新。
2. 點任一個情境可揭曉「凱琳老師的選擇」與理由；「全部揭曉」一次全開。
3. 第 43 頁「回頭看」再看一次結果，可做總結討論。

## 彩排與正式場次分開

- 正式：直接開 `index.html`。
- 彩排：網址加上 `?r=rehearsal`（例如 `index.html?r=rehearsal`），QR Code 也會帶到彩排場，票不會混在一起。
- 想開新的一場（另一場研習）：換成 `?r=任一英文代碼`。

## 注意

- 投票資料存在 Supabase 的 `ai_tool_votes` 資料表，只開放匿名「新增」與「讀取」，不收姓名或個資。
- QR Code 要在網站上線（GitHub Pages）後才能讓手機掃到；在本機開啟時只會顯示提示文字。
- 需要網路連線。
