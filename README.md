# AI 神隊友｜教師的 AI 工作流實作

32 頁、16:9、響應式教師研習網頁簡報。內容以「真實教師任務」為主線，串起 ChatGPT、Gemini 與 Gemini Notebook，並與 Google 操作筆記及 Padlet 互相搭配。

## 線上簡報

[開啟 GitHub Pages 網頁簡報](https://ab0308-del.github.io/ai-teaching-workflow-workshop/)

## 三件套分工

- 網頁簡報：現場帶領、示範、任務、轉場與提示詞快速複製。
- Google 操作筆記：完整步驟、完整提示詞、實作檢核與課後延伸。
- Padlet：資源入口、成果分享、提問與回饋。

網頁內的每個實作提示詞都能直接展開與複製，不需離開簡報才能操作；同時保留操作筆記與 Padlet 的固定入口。

## 使用方式

1. 使用 Chrome 或 Edge 開啟 `index.html`。
2. 使用方向鍵、PageUp、PageDown、空白鍵、點擊或下方按鈕換頁。
3. 右上方可開啟操作筆記、Padlet、目錄、講者備註與全螢幕。
4. 按 `N` 可快速顯示或隱藏講者備註。
5. 網址尾端可使用 `#slide-08` 等格式直接開啟指定頁。

## 專案結構

- `index.html`：網頁結構、目錄、講者備註與提示詞視窗。
- `styles.css`：16:9 投影、手機版面、配色與元件樣式。
- `slides-data.js`：32 頁文案、講者備註、完整提示詞與資源連結。
- `app.js`：頁面產生、提示詞複製、導覽、目錄與全螢幕。
- `teacher.png`、`teacher-sprite.png`：講師照片與人物識別。
- `assets/`：課程示意圖與工具視覺素材。

## 設計原則

- 投影片只顯示現場需要看的重點；完整內容保留在內嵌提示詞與 Google 操作筆記。
- 任何 AI 產出都視為初稿，進入教學前由教師查核與修訂。
- 網頁不連接真實 AI API，也不收集或處理學生個資。
- 桌機、投影、平板與手機皆可閱讀和操作。
